# Contributing 贡献指南

Thanks for wanting to improve or mod these projects.

## Pull requests

1. Fork the repository.
2. Create a branch with a short descriptive name, for example `midi-to-cv/encoder-fix`.
3. Keep changes scoped to one project or one document when possible.
4. Describe the hardware setup you tested on and what you measured.
5. Open the pull request against `main`.

## Mods

Mods are welcome. Please document:

- the project and firmware version you started from
- wiring and pin changes
- any calibration values that must change
- known limitations or side effects

## Code style

- Match the style of the file you are editing.
- Use English comments and identifiers.
- No secrets, API keys or personal paths in commits.
- Keep third-party code and reference documents with their original licenses.

## Licensing

By contributing you agree that your changes are released under the license of the part of
the repository you changed: GPL-3.0-or-later for firmware/software, CERN-OHL-S-2.0 for
hardware designs.
