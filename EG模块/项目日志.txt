EG模块 项目日志
================
版本：0.5（原理图+PCB 全板复核；对照数据手册）
记录日期：2026-11-04

一、需求
-------
- 2× ADSR（A/D/S/R）
- 2× AR（A/R）
- 4× Decay（单 Decay）
- 每一路都有 Gate 输入 + Retrigger 输入（全部带重触发）
- 8× CV 输出，0~10V（VCV/Eurorack 单极性 CV）
- Gate/Retrig 输入 0/10V，带保护
- 16 个模拟控制：8 个推子（ADSR）+ 8 个旋钮（AR/Decay）
- 24 个 LED：8 个输出 + 8 个 Gate + 8 个 Retrig
- 目标面板：20~24HP（20HP 偏紧，24HP 更舒服）

二、方案选择
-----------
- 从模拟方案改为数字方案：Pico 1（RP2040）
- 原因：多通道、retrigger/loop、曲线形状、通道一致性、扩展性；
  不需要模拟 VCA，模块保持为纯 CV/包络发生器
- 输出：1× DAC8568（8 通道、16 位、SPI、0~5V 内部基准）
  - 每路经 OPA4171AIDR 同相放大 2 倍 -> 0~10V（2 片四运放）
  - 8 路分配：ADSR1、ADSR2、AR1、AR2、Decay1~4
- 输入：2× ADS8688（8 通道、16 位、±10.24V、1MΩ、±20V OVP）
  - 一片读 8 路 Gate，一片读 8 路 Retrig
  - 每路 1k 串阻 + BAT54S 钳到 ±12V；ADS8688 内部 OVP 作为第二道保护
  - 15kHz 抗混叠滤波对 1ms trigger 没问题
  - 轮询 >= 10kHz，软件阈值 + 迟滞（例如 2.5V 开、2.0V 关）
- 模拟控制：1× CD74HC4067（16 通道 mux）+ Pico ADC
  - 8 推子 + 8 旋钮 = 16 路，正好一片
  - 5 根 GPIO（4 选择 + 1 ADC；使能脚接地）
  - mux 输出 10nF/100nF + 1k 到 ADC
- LED：1× TLC5947（24 通道、12 位 PWM、恒流）
  - 24 路刚好：8 输出 + 8 Gate + 8 Retrig
  - IREF 设 2~3mA，LED 不用串电阻
  - 短 trigger 做 30~50ms 脉冲展宽，否则肉眼看不清
- 电源：±12V；5V 由 LM7805 从 +12V 生成；3.3V 用 Pico 板载
  - 5V 估算 ~175mA；7805 功耗 ~1.2W，需要散热片
  - 如果机箱有稳定 +5V，可跳过 7805
- 保护：PTC ×2、肖特基 ×2、BAT54S 输入钳位、可选 TVS

三、引脚分配（草案）
-------------------
- SPI0（DAC8568）：GP2 SCK, GP3 MOSI, GP5 CS, GP6 LDAC
- SPI1（2× ADS8688）：GP10 SCK, GP11 MOSI, GP12 MISO, GP13 CS1, GP14 CS2
- CD74HC4067：GP16~GP19 选择, GP26 ADC
- TLC5947：GP20 SIN, GP21 SCLK, GP22 XLAT, GP15 BLANK
- 按钮（可选）：GP0, GP1, GP4
- 备用：GP7, GP8, GP9, GP27, GP28
- 说明：TLC5947 的 SPI 模式可能与 DAC/ADS 不同，必要时用 PIO 或单独 SPI

四、软件架构（计划）
-------------------
- Core 0：5~10kHz 定时器 -> 8 路包络计算 -> DAC8568 -> LDAC 同时锁存
- Core 1：1~5kHz -> ADS8688 Gate/Retrig 轮询 -> 每 0.2ms 扫一个 mux 通道 -> 按钮
- 参数通过双缓冲/无锁结构传给 Core 0
- 不在中断里 delay；不阻塞式扫完 16 路再更新 DAC
- DAC 用 LDAC 同步更新 8 路
- 包络引擎放 RAM（__not_in_flash_func）；编程完成后禁用 USB 中断
- 旋钮控制时间常数不需要平滑；Sustain/Level 加一阶低通防 zipper
- 上电先把 DAC 全写 0，LED 全灭，避免“噗”

八、2026-10-28 电源入口决定（暂停前）
------------------------------------
（注：本节关于“不加 TVS、5V 用 7805”的决定已被第九节取代）
- 不再加 PTC / TVS；只保留 SS54 串联反接保护（±12V）。
- +5V 由板上 LM7805 从 +12V 生成；16pin 的 +5V 不接。
- 原因：PTC 动作慢、有压降、反复过流；TVS 对短路无效；省板面积。
- 接受风险：模块内部短路时靠电源/LDO 限流和热关断；电流条/测温可发现。
- BOM 中 PTC1/PTC2、TVS1/TVS2 标为 DNP（不装）；D1/D2 改 SS54。
- +5 若以后改用总线 +5，不能串 SS54（压降到 4.6V，10V 输出会掉到 ~9V）；
  需改 crowbar/理想二极管/防呆座。
- 状态：暂停；恢复时先统一位号、补外围、连线。

十、2026-10-29 DAC8568 接法定稿
----------------------------
封装 TSSOP-16，逐脚：
- 3 AVDD → +5V（100nF + 10µF 到 GND）
- 14 GND → GND
- 8 VREFIN/VREFOUT → **10µF 到 GND**（内部基准输出；手册要求≥150nF，用 10µF 降噪）
- 9 CLR → +3V3（高电平，禁用清零）
- 1 LDAC → Pico GP6（8 路同时更新；或接 GND 则每帧立即更新）
- 2 SYNC → Pico GP5（片选）
- 15 DIN → Pico GP3（MOSI）
- 16 SCLK → Pico GP2（SCK）
- 4~7,10~13 VOUTA~H → 运放输入（未接）
要点：
- 内部 2.5V 基准默认关闭，固件需先发命令开启，否则无输出。
- AVDD 必须 ≥5V 才能出 0~5V（C 档）。
- 逻辑高门限 VIH=0.625×AVDD，5V 时=3.125V；Pico 3.3V 够用但余量小（~175mV）。
- 当前状态：Pico SPI 未接、8 路 VOUT 未接。

4. PIO 方案（全部 SPI/类 SPI 走 PIO）
- 4 个 SM：DAC（只写）、ADCA（全双工）、ADCB（全双工）、TLC（只写）。
- PIO0 = DAC + ADCA；PIO1 = ADCB + TLC（指令内存各 2 程序，够）。
- CS / XLAT / BLANK / LDAC 用普通 GPIO；硬件 SPI0/SPI1 留空备用。
- 引脚预算：SPI 16 + MUX 5 = 21（不装按钮），Pico 26，剩 5；COMMON 必须 GP26/27/28。
- DAC 电平：AVDD=+5V，VIH=0.625×5=3.125V，Pico 3.3V 满足（余量 ~175mV），不加电平转换。
