VCA模块 物料清单（BOM）
版本：6.1（2 路、1× LM13700、Eurorack 100k 输入 / 1k 输出、按作者现有库存）
日期：2026-11-10
状态：设计冻结（原理图前；明天开始画）

概述
  2 路独立模拟 VCA，1× LM13700M-TD（双 OTA），1× TL074，2× 2N3906，2× 2N3904。
  每路：Audio In / CV In / Audio Out / 1× B10k Level（CV 衰减）/ 1× CV LED。
  CV 不插线就没有声音（和 Benjiao MiniVCA 一致）。
  纯模拟，无 MCU，无固件，无音频 LED，无 +5V/+3V3/基准。±12V。目标 6~8HP。

来源
  原始电路 Juanito Moore；单路 Benjiao Modular MiniVCA（MIT）；资料整理 小蔡（Ciiyte）。
  本 BOM 为 2 路改动版，阻值按作者现有库存（22k/100k/470r/56k/1k）替换，
  并按 Eurorack de facto 标准（输入 100k、输出 1k）调整；去掉第二 CV 支路和音频 LED。

============================================================================
三、每路接线（外部网络）
============================================================================
3.1 音频输入
  J(IN) tip → 1k(RIN) → BAT54S 钳位 → R6 100k → 节点 A
  节点 A → R7 470r → GND
  节点 A → OTA 的一个输入（In+ 或 In-，按 Benjiao 原图）
  OTA 另一个输入 → R5 470r → GND
  → 10Vpp 经 R6/R7 分压 ≈1/214，约 47mVpp 进 OTA

3.2 CV 输入 / Level
  J(CV) tip → 1k(RIN) → BAT54S 钳位 → RV 上端
  RV 下端 → GND
  RV 动片 → R3 22k → 控制运放反相输入（虚地）
  控制运放 → R8 22k → 2N3906 发射极；2N3906 基极 → 控制运放反相输入；
  2N3906 集电极 → LM13700 Iabc
  增益：gain = Level × CV / 10V；CV 不插 → 0 → 无声

3.3 CV LED（每路 1 组）
  CV 输入节点（1k 之后、电位器之前）→ RB 100k → 2N3904 基极
  2N3904 发射极 → GND
  2N3904 集电极 → LED 阴极；LED 阳极 → RL 1k → +12V
  说明：现在指示“CV 输入有无/大小”；若要指示“实际增益”，可把 RB 改接到电位器动片。

3.4 音频输出
  OTA 输出 → I/V 运放反相输入；R9 56k + C 120pF 反馈
  I/V 运放输出 → R10 1k → J(OUT) tip
  J(OUT) tip → BAT54S 钳位（GND/+12V）
  输出阻抗 = 1k

3.5 保护
  所有插孔：1k 串阻 + BAT54S（pin1=GND、pin2=+12V、pin3=信号）
  电源入口：SS54 防反接 + SMBJ15CA TVS + 100µF

============================================================================
五、电源 / 16pin
============================================================================
  16pin 脚位：1/2 = −12V；3–8 = GND；9/10 = +12V；11/12 = +5V（NC）；
              13/14 = CV（NC）；15/16 = Gate（NC）
  红条 = −12V，方向必须确认。
  本模块只用 ±12V 和 GND；+5V/CV/Gate 不接。
  退耦：每颗 IC 电源脚 100nF；每轨 10µF；入口 100µF。
  Doepfer 建议不用带方向键的牛角；若用牛角，必须确认 pin1/2 = −12V。

============================================================================
六、机械 / 面板
============================================================================
  3U 可用高度：128.5mm；1HP = 5.08mm。
  6HP：标称 30.48mm，实际约 30.1mm。
  8HP：标称 40.64mm，实际约 40.3mm。
  安装孔：≤10HP 用上下 2 个 M3 孔，孔距为 5.08mm 的整数倍。
  面板：2mm 铝或 1.6mm PCB；深度待布局，预计 <50mm。
  布局（2 列）：
    通道 1：IN / CV / OUT / Level 旋钮 / CV LED
    通道 2：IN / CV / OUT / Level 旋钮 / CV LED

七、电源估算
============================================================================
  +12V ≈ 15~20mA（LM13700 + TL074 + 2× 2N3906 + 2× CV LED）
  −12V ≈ 5mA（LM13700 + TL074 + 2N3906）
  以实测为准；不使用 +5V/+3V3。

============================================================================
八、Eurorack 符合性（对照 Doepfer / de facto）
============================================================================
  音频电平：10Vpp（±5V）✔；本机最大约 0.93×（约 9.3Vpp），在 10Vpp 范围。
  CV 电平：0~10V（Doepfer ADSR 典型 0~8V；0~10V 在 Eurorack 常见）✔
  Gate：无。
  输入阻抗：音频 101k ✔；CV 11k（B10k）△，B100k 时 101k ✔
  输出阻抗：1k ✔
  电源：±12V，16pin ✔
  面板：3U=128.5mm；6HP≈30.1mm / 8HP≈40.3mm；2 个 M3 孔，孔距 5.08 整数倍 △ 需按此画板
  保护：所有插孔 1k + BAT54S ✔
  16pin 牛角：红条 = −12V；方向必须确认。

============================================================================
九、关键设计点
============================================================================
  - CV 不插 = 无声：Level 只是 CV 衰减器，不做 +10V 常闭、不做手动 offset。
  - 去掉 Benjiao 的第二 CV 支路：RV2 不装，原 R4（20k）不装，对应节点接 GND。
  - 每路 2 运放（输入/求和 + I/V），2 路 4 个 → 1× TL074。
  - 每路 1× 2N3906 做 Iabc 电流源；R8 22k / R9 56k。
  - Eurorack 调整：R6 100k + R7 470r ≈ 1/214（约 47mVpp 进 OTA）；
    R3/R8 22k（控制电流约 −9%）；R9 56k 补偿，整体约 0.93×。
  - 音频输入阻抗 ≈101k；输出阻抗 1k；CV 输入阻抗 ≈11k（B10k）。
  - B10k 分压接法（上端 CV、下端 GND、动片→22k→虚地）；换 B100k 时同接法。
  - CV LED：CV 输入节点 →100k→2N3904 基极；集电极→LED 阴极；LED 阳极→1k→+12V。
  - 所有插孔 1k + BAT54S 钳位到 GND/+12V。
  - ±12V 防反接 SS54 + TVS SMBJ15CA；100µF 储能。
  - 无音频 LED、无指数、无第二 CV、无基准。
