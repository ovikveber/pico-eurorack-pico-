## 当前冻结方案（速查，2026-11-10）

- 2 路 VCA，1× LM13700M-TD（A/B 两个 OTA）+ 1× TL074 + 2× 2N3906 + 2× 2N3904。
- 每路：Audio In / CV In / Audio Out / B10k Level / CV LED。
- CV 不插 = 无声；`gain = Level × CV/10`（0~10V 钳位）。
- 关键阻值：**R6 100k、R7/R5 470r、R3/R8 22k、R9 56k、R10 1k**。
- 音频输入 ≈101k，输出 ≈1k；CV 输入 ≈11k（B10k，换 B100k 则 ≈101k）。
- 输入衰减 ≈1/214（约 47mVpp 进 OTA）；整体增益 ≈0.93×。
- 电源 ±12V，16pin；无 +5V/基准。
- 面板 6~8HP、3U；6HP 实际 ≈30.1mm，8HP ≈40.3mm。
- 不做：音频 LED、指数、第二 CV、+10V 常闭、手动 offset。
- 详细物料/接线/差异表见 `BOM-物料清单.txt`（版本 6.1）。

## 1. 目标与范围

做一个 2 路纯模拟 VCA：

- 2× 独立 VCA（1× LM13700M-TD，双 OTA）
- 每路：Audio In / CV In / Audio Out
- 每路：**1× B10k Level 旋钮**（CV 衰减器）
- 每路：**1 个 CV LED**（指示 CV 有无/大小）
- `增益 = Level × CV/10`，线性，CV 钳位 0~10V
- **CV 不插 = 无声**（不做 +10V 常闭，不做手动 offset）
- 不反相，不做指数
- 无音频 LED、无第二 CV、无 MCU、无固件
- ±12V，16pin
- 面板尽量小：6HP（紧）~ 8HP（稳）

### 不做

- +10V 基准 / CV 常闭 / 手动 offset
- 音频 In/Out LED
- 指数响应
- 第二 CV 输入 / CV 衰减器
- 双极性 / 反相
- 过零检测、软静音、自动增益
- 数字控制、预设

理由：作者已有一台 Benjiao MiniVCA，行为和它保持一致——**没插 CV 就没声**；
2 路是为了面板放得下（4 路放不下），电路最简、成本最低。

## 3. 芯片与引脚

LM13700M-TD：SOP-16，双 OTA + 双缓冲。引脚（功能）：

| 功能 | A 路 | B 路 |
| --- | --- | --- |
| Iabc（放大器偏置电流） | 1 | 16 |
| Diode Bias（线性化二极管偏置） | 2 | 15 |
| Input+ | 3 | 14 |
| Input− | 4 | 13 |
| Output（无缓冲） | 5 | 12 |
| Buffer Input | 7 | 10 |
| Buffer Output | 8 | 9 |
| V− | 6 | — |
| V+ | 11 | — |

关键数据（数据手册）：

- `gm ≈ 19.2 × Iabc`（25°C，Iabc 单位 µA，gm 单位 µS）
- Iabc 引脚约在 `V− + 2Vbe`（±12V 时约 −10.6V）
- Iabc 绝对最大 2mA；峰值输出电流约 500µA
- 本模块沿用 Benjiao 的用法：外部 TL074 做 I/V，缓冲器不用

## 4. 通道数与架构

```
1× LM13700M-TD = 2 路 VCA（A/B 两个 OTA）

每路（沿用 Benjiao 单路）：
  Audio In ─ 保护 ─ R6 100k ─ R7 470r ─ R5 470r ─ OTA
                                        │ Iabc
  CV In ─ 1k ─ B10k(Level) ─ R3 22k ─ 求和运放 ─ 2N3906 电流源 ─┘
                                        │
                     OTA 输出 ─ I/V 运放 ─ R10 1k ─ 保护 ─ Audio Out

  CV LED：CV 节点 ─ 100k ─ NPN 基极；发射极 GND；集电极 ─ LED ─ 1k ─ +12V
```

- 每路 2 个运放（输入/求和 + I/V），2 路共 4 个 → **1× TL074**（或 TL084）。
- 每路 1 只 **2N3906**（PNP）做 Iabc 电流源。
- 每路 1 个 **B10k** 电位器（分压接法）。
- 去掉 Benjiao 的第二 CV 支路（RV2 + R4）：RV2 不装，其对应求和电阻接 GND。
- 不做 +10V 常闭：CV 插座用普通插座即可，不接基准。
- 每路 1 个 CV LED（NPN 驱动），不做音频 In/Out LED。

## 5. 每路控制与计算

### 5.1 Level / CV

Benjiao 的电位器接法（从 `.sch` 追出）：

```
CV 插口 tip → 电位器上端
电位器下端 → GND
电位器动片 → R3 22k → 运放虚地
```

- 这是**分压接法**，所以 **B10k 可直接用**；电位器值只影响输入阻抗和曲线，不影响 0/100%。
- 电位器只衰减 CV：
  - 不插 CV：CV = 0 → 增益 = 0 → **无声**。
  - 插 CV：`增益 = Level × CV/10`。

### 5.2 B10k 的曲线

电位器动片经 22k 接到运放**虚地（0V）**，所以 22k 相当于并联在电位器下半段：

- 动片在 100%：输出 = CV（满）。
- 动片在 0%：输出 = 0。
- 动片在 50%：由于 22k 负载，约 **45%** 而不是 50%（曲线轻微压缩）。

做 CV 量够用；若要更接近线性，可把 R3 从 22k 加大（需同时看运放增益），列为可选优化。

### 5.3 增益公式

```
gain = Level × (CV / 10V)      // CV 钳位 0~10V
没插 CV → gain = 0 → 无声
```

- Level：0~100%，不反相。
- CV：负电压/超过 10V 按 0/10V 处理。

## 6. CV LED

每路 CV 口加 1 个 LED，用来指示 CV 有没有/多大：

```
CV 节点 ── 100k ── NPN 基极（2N3904）
                   发射极 → GND
                   集电极 → LED → 1k~2.2k → +12V
```

- 100k 基极电阻只取几十 µA，对 CV 节点影响很小。
- CV 0~10V：LED 稳定亮，亮度随 CV。
- CV 是音频速率时会闪；慢速包络/LFO 时跟随。
- 不做 Audio In / Audio Out LED（意义小，面板也放不下）。
- 2 路共：2× NPN、2× 100k、2× 1k、2× LED。

## 7. 为什么不做 +10V 常闭

之前考虑过用 +10V（BZX84C10 齐纳）接到 CV 插座常闭脚，让"没插 CV 时 Level 当音量"。
现在决定**不做**，原因：

1. 作者已有 Benjiao MiniVCA，它本来就是"CV 不插 = 无声"，沿用最省心。
2. 去掉齐纳、Rs、退耦电容和带开关的插座，BOM 更少、成本更低。
3. 不再有"10k 电位器把基准拖垮 / Rs 取值"的问题。
4. 这个 VCA 的典型用法就是 EG/LFO 进 CV 控制音量，没 CV 本来就不需要出声。

代价：没有手动 offset，不插 CV 时 Level 旋钮无效。可接受。

如果以后想要"没 CV 也有手动音量"，再单独加 +10V 常闭或加 offset 支路，不影响现在的音频路径。

## 8. 音频路径与保护

沿用 Benjiao：

- 输入：R6 100k → R7 470r → OTA。
  - R6 100k + R7 470r 是**把 10Vpp 衰减到约 47mVpp** 的 OTA 输入衰减，必须保留；
    LM13700 输入只能吃几十 mV，直接给 10Vpp 会严重失真。
  - 本仓库在插孔处再加 **1k 串阻**（Eurorack 保护），它和 100k/470r 的衰减是两回事：
    1k 负责保护，100k/470r 负责衰减。
  - 音频输入阻抗 ≈ 1k + 100k ≈ **101k**（符合 de facto 100k；1k 只是保护）；
    CV 输入阻抗 ≈ 1k + B10k ≈ **11k**（换 B100k 则 ≈101k）。
- 控制：CV → Level → R3 22k → 运放 → **2N3906（PNP）电流源** → OTA Iabc。
  - 2N3906 只在控制路径，不碰音频；它把 CV 变成 Iabc，少了它 VCA 关不死。
- CV LED：100k → **2N3904（NPN）** → LED。只在 LED 支路，不做 LED 可整组省掉。
- 输出 I/V：56k 反馈 + 120pF；R10 1k → 输出（输出阻抗 1k）。
- 每路 2 个运放，2 路 4 个 → 1× TL074。

本仓库额外加保护（Benjiao 原版没有）：

| 位置 | 方案 |
| --- | --- |
| Audio In | 1k 串阻 + BAT54S 钳位（GND/+12V） |
| CV In | 1k 串阻 + BAT54S 钳位 |
| Audio Out | 1k 串阻 + BAT54S 钳位 |
| 电源 | ±12V 防反接 + TVS（SS54 + SMBJ15CA 或同类） |

### Eurorack 符合性（对照 Doepfer / de facto）

| 项目 | 标准 | 本模块 | 结论 |
| --- | --- | --- | --- |
| 音频电平 | 10Vpp（±5V） | 10Vpp 设计，最大约 0.93× | ✔ |
| CV 电平 | 0~10V 常见（Doepfer ADSR 0~8V） | 0~10V，钳位 | ✔ |
| Gate | 0/+5V，>3V 高 | 无 Gate | — |
| 音频输入阻抗 | 100k（de facto） | 101k | ✔ |
| CV 输入阻抗 | 100k（de facto） | 11k（B10k）/ 101k（B100k） | △ |
| 输出阻抗 | 1k（de facto） | 1k（R10） | ✔ |
| 电源 | ±12V/+5V，16pin | ±12V，16pin | ✔ |
| 面板 | 3U=128.5mm，HP=5.08mm | 6/8HP | ✔（按实际宽度） |
| 保护 | — | 所有插孔 1k+BAT54S | ✔ |

- 电源 16pin：1/2 −12V、3–8 GND、9/10 +12V、11/12 +5V、13/14 CV、15/16 Gate；红条 = −12V。
- 面板实际宽度应比标称小 0.3~0.4mm：6HP≈30.1mm，8HP≈40.3mm；≤10HP 用上下 2 个 M3 孔，孔距 5.08mm 整数倍。
- 唯一不严格符合的是 CV 输入阻抗（B10k=11k）；要 100k 就换 B100k。

### 与仓库其它模块的一致性

| 模块 | 输出 | 输入 |
| --- | --- | --- |
| EG | 运放 → 1k → 插孔 + BAT54S；CV 0~10V | 1k → BAT54S → ADS8688（1MΩ） |
| midi to cv | 运放 → 1k → 插孔 + BAT54S；CV ±5V / Gate 0~10V | — |
| 可编程 VCO | 10µF + 1k + BAV99 | 1k + BAV99 → 100k 缓冲 / ADS8688（1MΩ） |
| 本 VCA | I/V → 1k → 插孔 + BAT54S | 音频 1k + 100k/470r ≈101k；CV 1k + 10k ≈11k |

- 输出 1k + BAT54S、音频输入 101k 与仓库其它模块一致。
- CV 输入 11k 比 EG/VCO 的 1MΩ/100k 低，但可用（作者接受）。
- 电平：EG 输出 0~10V，本 VCA 按 0~10V 设计，完全匹配。
- CV 极性：midi to cv 的 CV 是 ±5V，进本 VCA 时负半周被钳到 0，只用到正半周（约 0~50% 增益）；
  用 EG/LFO 的 0~10V 则满量程。这是单极性 VCA 的正常行为。

## 9. 电源

- 只用 **±12V**（16pin 总线），不用 +5V/+3V3，也不用基准。
- LM13700 静态约 2.2mA；2× 2N3906 很小；1× TL074 约 2mA；2 个 LED 约 8mA。
- 估算：+12V 约 15~20mA，−12V 约 5mA，以实测为准。
- 每颗 IC 电源脚就近 100nF；电源入口 100µF。
