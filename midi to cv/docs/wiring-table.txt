MIDI-to-CV 接线表  (12HP / 8 复音)
主控: Raspberry Pi Pico / RP2040
DAC:  DAC8568 (八路 16bit, 内部 2.5V 基准 = 0-5V, TSSOP-16)
缓冲: 2x 74AHCT541  (U19 = SPI 3.3V->5V 电平转换 ; U20 = 8x Gate 缓冲)
显示: 1.3" ST7789 SPI OLED (TFT1)   人机: EC11 旋转编码器(带按键)
接口: 17x 3.5mm 单声道座 = 8xCV + 8xGate + 1x 私有数字总线
2026-10-16

================================================================
一、引脚总表 (Pico GPIO -> 功能)
----------------------------------------------------------------
下排 (脚21-40, 朝芯片侧):
  GP28 (脚34)  DAC SCLK
  GP27 (脚32)  DAC DIN(MOSI)
  GP26 (脚31)  DAC CS(SYNC#)
  GP22 (脚29)  Gate1 -> U20 A1
  GP21 (脚27)  Gate2 -> U20 A2
  GP20 (脚26)  Gate3 -> U20 A3
  GP19 (脚25)  Gate4 -> U20 A4
  GP18 (脚24)  Gate5 -> U20 A5
  GP17 (脚22)  Gate6 -> U20 A6
  GP16 (脚21)  Gate7 -> U20 A7
上排 (脚1-20):
  GP15 (脚20)  Gate8 -> U20 A8
  GP14 (脚19)  私有总线 T (发送, PIO UART)
  GP13 (脚17)  编码器 A
  GP12 (脚16)  编码器 B
  GP11 (脚15)  编码器 SW
  GP10 (脚14)  OLED SCL
  GP9  (脚12)  OLED SDA(MOSI)
  GP8  (脚11)  OLED RST
  GP7  (脚10)  OLED DC
  GP6  (脚9)   OLED CS
  GP5  (脚7)   OLED BL
  备用: GP0 GP1 GP2 GP3 GP4
  电源: 3V3=脚36 ; +5V(VSYS)=脚39 ; GND=脚3/8/13/18/23/28/33/38

================================================================
二、电源 (来自 Eurorack 16pin)
----------------------------------------------------------------
CN1 (2x8 简易牛角/IDC, 标准 Doepfer 16pin 脚位):
  1,2      -12V    (本模块不用)
  3~8      GND
  9,10     +12V    (不用)
  11,12    +5V     <-- 本模块用
  13,14    CV bus  (不用)
  15,16    Gate bus(不用)
  红边 = -12V, 插线时红边朝 bus 上 -12V 丝印那侧。

模块内部:
  +5V  -> Pico VSYS(脚39) / DAC AVDD(3) / U19 VCC(20) / U20 VCC(20) / 5V去耦
  +3V3 (Pico 脚36) -> 只给 OLED VCC (TFT1 脚2)
  去耦: C1,C4 = 3V3 ; C2,C3,C5 = 5V(0.1µF) ; C6 = 5V(10µF bulk) ; C7 = DAC VREF(0.1µF)
  DAC VREFIN/VREFOUT(8) -> C7 0.1µF -> GND
  DAC LDAC#(1) -> GND ; DAC CLR#(9) -> +5V
  U19/U20 OE1#(1) & OE2#(19) -> GND ; 未用输入 A4-A8 -> GND ; 未用输出 Y4-Y8 -> GND

================================================================
三、DAC 链 (Pico -> U19 缓冲 -> U18 DAC8568)
----------------------------------------------------------------
  GP28 -> U19 A1(2) -> U19 Y1(18) -> DAC SCLK(16)
  GP27 -> U19 A2(3) -> U19 Y2(17) -> DAC DIN(15)
  GP26 -> U19 A3(4) -> U19 Y3(16) -> DAC SYNC#(2)
  (电平转换理由: 5V 供电 DAC 的 VIH=0.7*VDD=3.5V, Pico 3.3V 打不动;
   74AHCT541 输入阈值 2.0V, 3.3V 可驱动, 输出 5V。只翻译数字线, 不碰模拟输出)

================================================================
四、Gate 链 (Pico -> U20 缓冲 -> 8 个 Gate 座)
----------------------------------------------------------------
  GP22 -> U20 A1(2)  -> Y1(18) -> U1  Gate 座
  GP21 -> U20 A2(3)  -> Y2(17) -> U3  Gate 座
  GP20 -> U20 A3(4)  -> Y3(16) -> U5  Gate 座
  GP19 -> U20 A4(5)  -> Y4(15) -> U7  Gate 座
  GP18 -> U20 A5(6)  -> Y5(14) -> U16 Gate 座
  GP17 -> U20 A6(7)  -> Y6(13) -> U14 Gate 座
  GP16 -> U20 A7(8)  -> Y7(12) -> U12 Gate 座
  GP15 -> U20 A8(9)  -> Y8(11) -> U10 Gate 座
  (Gate 电平 0V/5V, V-trig)

================================================================
五、CV 输出 (DAC -> 8 个 CV 座)
----------------------------------------------------------------
  VOUTA(4)  -> U9  CV 座
  VOUTB(13) -> U2  CV 座
  VOUTC(5)  -> U11 CV 座
  VOUTD(12) -> U4  CV 座
  VOUTE(6)  -> U13 CV 座
  VOUTF(11) -> U6  CV 座
  VOUTG(7)  -> U15 CV 座
  VOUTH(10) -> U8  CV 座
  (0-5V, 1V/oct; 内部基准, 无需标定)
  注: VOUT 到座子的顺序被打乱(PCB 走线), 以"十、"总表为准。

================================================================
六、OLED (TFT1, ST7789 SPI)
----------------------------------------------------------------
  1 GND  -> GND
  2 VCC  -> +3V3 (Pico 脚36)
  3 SCL  -> GP10
  4 SDA  -> GP9  (MOSI)
  5 SDO  -> 悬空 (不用)
  6 RST  -> GP8
  7 DC   -> GP7
  8 CS   -> GP6
  9 CSF  -> +3V3
  10 BL  -> GP5  (背光, 可 PWM)
  SPI 用 PIO (这套脚不对应硬件 SPI 组); SCL/SDA 相邻便于等长。

================================================================
七、旋转编码器 (EC11, U23)
----------------------------------------------------------------
  A   -> GP13
  B   -> GP12
  SW1 -> GP11
  C   -> GND   (旋转公共端)
  SW2 -> GND   (按键另一端)
  GP11/12/13 用 Pico 内部上拉; 建议 A/B 各 100nF 到 GND 抗抖。

================================================================
八、私有数字总线 (3.5mm 座 U17, 单向)
----------------------------------------------------------------
  用途: 本模块向"纯数字合成器"系列里的复音 VCO 发送复音/音符数据。
  T(Tip)   -> GP14   (数据输出)
  R(Ring)  -> GND
  S(Sleeve)-> GND
  单向只发 (无接收需求); PIO UART, 3.3V 直连 (两端都是 Pico)。
  发送端串 33~100Ω。 帧格式(建议): [0xAA][voice][note][gate][bend][CRC]

===============================================================
十、组别 / 输出映射总表  (★接 CV/Gate 座子的依据)
===============================================================
  约定: 一个"组" = 一路复音 = 1 根 Gate 线(GPIO, 经 U20) + 1 根 CV 线(DAC)。
        组号 = 物理座子对 (U1&U2=组1, U3&U4=组2, ... U15&U16=组8)。
        U1..U8: 奇=Gate 偶=CV ; U9..U16: 奇=CV 偶=Gate (PCB 排布所致)。
        ★DAC 通道顺序被 PCB 走线打乱, 下表为唯一依据。

  组  Gate座  CV座   Gate GPIO  Gate缓冲  CV(DAC)  DACaddr  MIDI
  --  ------  ----   --------   -------   ------   ------   ----
  1   U1      U2     GP22       Y1        VOUTB    B(1)     ch1
  2   U3      U4     GP21       Y2        VOUTD    D(3)     ch2
  3   U5      U6     GP20       Y3        VOUTF    F(5)     ch3
  4   U7      U8     GP19       Y4        VOUTH    H(7)     ch4
  5   U10     U9     GP15       Y8        VOUTA    A(0)     ch5
  6   U12     U11    GP16       Y7        VOUTC    C(2)     ch6
  7   U14     U13    GP17       Y6        VOUTE    E(4)     ch7
  8   U16     U15    GP18       Y5        VOUTG    G(6)     ch8

  说明:
  - Gate 走数字: Pico GPIO 经 U20(74AHCT541) 缓冲, 0V/5V V-trig。
  - CV 走模拟: DAC8568 输出, 0-5V / 1V/oct, 内部基准无需标定。
  - 座子 pin1=Sleeve=GND, pin3=Tip=信号, pin2=开关脚(悬空, 不接地)。
  - 固件 midi2cv.ino 的 gatePin[]/dacCh[] 与此表一一对应。
