# 可编程 VCO 模块 设计决定日志

- 状态：设计决定（原理图前；以文末 2026-10-20 修订为准）
- 日期：2026-10-20
- 主控：Pico 2 / RP2350（推荐）
- 定位：JP-8000 风格 supersaw 复音 VCO（单独 VCO，不是通用平台），不含 LFO 模式
- 协议：固件 GPL-3.0-or-later；硬件 CERN-OHL-S-2.0

> **注意：2026-10-20 的讨论已放弃“通用可编程平台”方向。文末第 19 节是当前有效方案；前面章节中与第 19 节冲突的内容以第 19 节为准。**

---

## 1. 目标与范围

做一个 8 voice 复音的 JP-8000 风格 supersaw VCO：

- 从 midi2cv 模块的 GP14 私有总线接收 8 个 voice 的 note/gate/bend 数据
- 8 voice × 4 saw = 32 个振荡器；RP2350 可做到 8 voice × 7 saw = 56 个
- 立体声 10Vpp 音频输出
- 4 路音频速率调制输入（Audio Mod）
- 8 路慢速 CV 调制输入（CV Mod）
- Audio Matrix / CV Matrix 两层调制矩阵
- 不做 LFO 模式，不做 gate/trig，不做第二振荡器

---

## 2. 术语定义

| 术语 | 定义 |
|---|---|
| **Audio Mod 口** | PCM1865 的 4 路音频速率输入 |
| **CV Mod 口** | ADS8688 的 8 路慢速 CV 输入 |
| **Audio Matrix** | Audio Mod 1–4 → FM/PM/PWM/RM/AM 的 4×5 base amount |
| **CV Matrix** | CV Mod 1–8 → 25 个目标的 8×25 depth |
| **Amount** | Audio Matrix 里的静态发送量 |
| **Depth** | CV Matrix 里的动态调制量 |
| **Target** | CV Matrix 的目标，可以是 20 个 Audio Matrix cell，也可以是 Detune/Mix/Shape/Spread/Waveform |
| **V/oct** | CV Mod 1，默认锁定，不参与矩阵 |

说明：

- CV Matrix 仍然是矩阵，只是 UI 采用 **destination-centric**（类似 Serum）：先选目标，再调各个 CV 到这个目标的 depth。
- “全自由路由”指任意 CV 可以送到任意目标，且可以同时送多个目标；量在目标那边调。

## 3. 总体架构

```
midi2cv (RP2040)
    │  GP14 私有总线：voice / note / gate / bend / ...
    ▼
Pico 2 (RP2350, VCO 主控)
    │
    ├── PCM1865（4ch ADC，Audio Mod 1–4）
    │       └── Audio Matrix 4×5（20 个 amount）
    │               └── FM / PM / PWM / RM / AM
    │
    ├── ADS8688（8ch ADC，CV Mod 1–8）
    │       └── CV Matrix 8×25（200 个 depth）
    │               ├── 20 个 Audio Matrix cell
    │               └── Detune / Mix / Shape / Spread / Waveform
    │
    ├── Sync（比较器 + GPIO/PIO）
    │
    ├── PCM5102A（立体声 DAC）
    │       └── OPA1612 增益 1.68 → 10Vpp L/R
    │
    └── UI：5 个参数编码器 + 1 个导航编码器 + 屏幕 + 0–2 按钮
```

## 5. Audio Mod 输入

### 芯片

- **PCM1865**：4 通道、24bit、192kHz、110dB、PGA −12～+32dB、I2C/SPI、TSSOP-30、3.3V、约 41 元。
- 一颗 PCM1865 就够 4 路 Audio Mod；第二颗暂不设计。

### 关键限制

PCM1865 不能直接吃 10Vpp：

- 模拟输入绝对最大：**−1.7V ～ 5.0V**
- 单端满量程：**2.1Vrms = 5.94Vpp**
- 10Vpp = ±5V 会超绝对最大
- PGA 不能扩展输入引脚范围；PGA 只是在允许范围内调增益

### 输入级

```
Jack → 1k + BAV99 → 100k 输入缓冲 → 0.5 衰减 → 10µF → PCM1865
```

- 10Vpp → 5Vpp，PCM1865 满量程 5.94Vpp，约 1.5dB headroom
- 输入折算 SNR ≈ 110 − 6 = **104dB**
- AC 耦合，offset 被隔直；PCM1865 输入自偏置到 AVDD/2
- 输入引脚实际摆幅约 −0.85V～4.15V，在 −1.7V～5.0V 以内
- 运放：OPA4197（±12V）或 OPA2320（5V），一颗四运放做 4 路
- 这不是精密 DC 增益级：offset 被 AC 耦合隔掉，增益误差可由 PGA/软件校准
- 前面 1k + BAV99 保护；后面 10µF 隔直

### PGA

- PGA 设 0dB 左右，用于微调
- 不做外部衰减时不能直接接 10Vpp；0.5 衰减是必须的

## 6. CV Mod 输入

### 芯片

- **ADS8688**：8 通道、16bit、500kSPS aggregate（多路复用，每通道 62.5kSPS）、
  ±10.24V/±5.12V、1MΩ、±20V 过压保护、SPI、内部 4.096V 基准（6ppm/°C）。

### 连接

- 直接接插孔：`1k + BAV99`，不需要运放/衰减
- CV1 = **V/oct 锁定**
- CV2–8 = 可分配
- 每通道按功能设量程：
  - V/oct：±5.12V（0.19 cent/LSB）
  - 0–5V 功能：0–5.12V
  - ±5V/0–10V 功能：±5.12V 或 0–10.24V
- 扫描率 1–8kHz，DSP 里平滑/插值

### 重要边界

- Sync / Gate / Trig 不走 ADS8688，必须走比较器/GPIO
- ADS8688 只做慢速 CV；音频速率调制必须走 PCM1865

## 7. Audio Matrix

### 结构

```
4× Audio Mod × 5 目的地 = 20 个 base amount
目的地：FM / PM / PWM / RM / AM
```

### UI

- 选择 Audio Mod 1–4
- 5 个参数编码器 = FM / PM / PWM / RM / AM 的 amount

### 语义

- Audio Matrix 编码器**只控制 amount**
- 不控制 depth；depth 在 CV Matrix 页
- amount 是静态发送量，CV depth 是动态叠加

### 调制实现

- **FM**
  - Lin：`f = f0 + k × fm`
  - Exp：`f = f0 × 2^(k × fm)`
  - 指数因子每个采样只算一次，再乘到每个 saw 的增量上
- **PM**：`phase_offset += pm × mod`
- **PWM**：`pulse_width = base + pwm × mod`，clamp
- **AM**：`out ×= (1 + am × mod)`
- **RM**：`out ×= rm × mod`
- FM Lin/Exp 用面板钮子开关选择；切换时 5–10ms 交叉淡化，避免音高跳变

## 8. CV Matrix

### 结构

```
8× CV Mod × 25 目标 = 200 个 depth
目标：
  FM1..FM4
  PM1..PM4
  PWM1..PWM4
  RM1..RM4
  AM1..AM4
  Detune
  Mix
  Shape
  Spread
  Waveform/Morph
```

### UI

- **destination-centric**：先选目标
- 5 个参数编码器 = CV1–5 的 depth
- Page 切 CV6–8
- 一个 CV 可以同时送到多个目标
- 多个 CV 可以同时送到一个目标，DSP 相加
- depth 可正可负（−100%～+100%）

### 合成

```
eff_audio[src][dest] = clamp(
    base[src][dest]
    + Σ_cv cv_depth[cv][(src,dest)] × cv_value[cv],
    −1, +1)

param[target] = base_param
    + Σ_cv cv_depth[cv][target] × cv_value[cv]
```

### 说明

- CV Matrix 不是“没有矩阵”；它是 8×25 矩阵，只是编辑方式在目的地。
- FM Index / PM Index / PWM Index / RM Index / AM Index 都是 CV Matrix 的 target，不需要单独的 Index CV 输入。
- CV Matrix 量大部分为 0；预设保存非零路由与 depth。

## 9. 调制目的地与 DSP

### 目的地

- FM（Lin/Exp）
- PM
- PWM
- RM
- AM
- Detune（supersaw 失谐）
- Mix（中心 saw vs 失谐 saw）
- Shape（波形/音色变形）
- Spread（立体声宽度，可选）
- Waveform/Morph（连续变形；离散波形由面板按钮/开关选择）

### 不做

- Feedback
- Symmetry / Bias
- 第二 V/oct
- LFO 模式
- 离散 Waveform 的 CV 切换（避免 clicks；如果以后加，需 crossfade）

### Base 参数

- Audio Matrix 的 20 个 amount 由编码器页面设置。
- Detune / Mix / Shape / Spread / Pulse Width 的 base 建议用面板电位器，便于现场演奏。
- 如果面板空间不足，可加一页 PARAM，用 5 个编码器设这些 base；这是待定项。

## 10. 复音、振荡器与主控

### 复音

- midi2cv 通过 GP14 发送 8 个 voice。
- VCO 做 8 voice。
- 8 voice × 4 saw = **32 个振荡器**（RP2040 可行，固定点）
- 8 voice × 7 saw = **56 个振荡器**（RP2350 / Pico 2）
- 推荐 RP2350 / Pico 2。

### DSP

- PolyBLEP 抗混叠
- 立体声 spread
- 8 voice 求和、限幅、DC 阻断
- 音频采样率 48kHz
- core0：音频 DSP
- core1：UI、ADS8688、PCM1865 配置、PCM5102A、GP14 总线、预设

### MIDI 总线

- GP14 单线、单向、3.3V PIO UART，发送端串 33–100Ω
- 当前帧建议：
  ```
  [0xAA][voice][note][gate][bend][CRC]
  ```
- 建议扩展：
  ```
  [0xAA][voice][note][gate][velocity][bend][aftertouch][modwheel][CRC]
  ```
- VCO 可把 Velocity / Aftertouch / Mod Wheel / Bend 作为 CV Matrix 的虚拟 source（待定/建议）
- 8 voice 数据量小；按事件发送即可，波特率 1Mbps 以上

## 11. UI、编码器与预设

### 硬件

- **6 个编码器**：
  - 5 个参数编码器（带按键）
  - 1 个导航编码器（带按键）
- 0–2 个小按钮（Back / Preset，可选）
- 屏幕：1.3" ST7789 240×240（推荐）或 0.96" OLED
- 可选 4 个面板电位器：Detune / Mix / Shape / Spread base

### 页面

#### Page 1：Audio Matrix

- 选择 Audio Mod 1–4
- 5 个参数编码器 = FM / PM / PWM / RM / AM 的 amount
- 只调 amount，不调 depth

#### Page 2：CV Matrix

- 选择 target（25 个）
- 5 个参数编码器 = CV1–5 的 depth
- Page 切 CV6–8
- 屏幕显示：
  ```
  Target: FM2
  CV1  +20%
  CV2    0%
  CV3  +50%
  CV4    0%
  CV5  -10%
  ```

#### Page 3：CV Input

- 5 个参数编码器 = CV1–5 的 Input Gain / Range
- Page 切 CV6–8
- 每个 CV：Input Gain（−100%～+100%）、Range（0–5V / ±5V / 0–10V）

#### Page 4：Global

- V/oct 范围
- Sync Hard/Soft
- Octave / Waveform
- 预设保存/加载

### 导航编码器

- 旋转：选择页面 / source / target
- 按下：进入/确认
- 长按：返回/保存

### 预设

- 建议 8–16 组
- 保存：Audio Matrix、CV Matrix、CV Input、Global 设置
- 存 EEPROM/flash
- 预设是 200 个 CV depth 可用性的关键

### 平滑

- CV depth、Input Gain、base amount 变化做 slew/one-pole
- 避免 zipper noise

## 12. 电平、电源、保护与布局

### 音频输出

- PCM5102A：2.1Vrms、接地中心、DC 耦合
- OPA1612 同相增益 **1.68**（Rf=6.8k，Rg=10k）→ 10Vpp
- 输出：10µF 薄膜 + 1k + BAV99 钳位
- 不做 LFO 模式；音频输出只做音频

### 保护

- 所有插孔：1k 串联 + BAV99 钳位到 ±12V/3.3V（按节点）
- Audio Mod：缓冲/衰减后再进 PCM1865
- CV Mod：ADS8688 自带 ±20V OVP，仍加 1k + BAV99
- Sync：比较器输入保护，阈值/迟滞
- 输出：100Ω–1k + 钳位

### 电源

- ±12V：运放（OPA4197/OPA1612）
- +5V：ADS8688 模拟
- +3.3V：PCM1865、PCM5102A、Pico
- 模拟 3.3V/5V 用低噪声 LDO/磁珠；数字/模拟分区
- 4 层板，完整地平面，星形接地
- PCM5102A 电荷泵噪声源远离 CV 与 Audio Mod 输入

### 时钟

- 音频域共用 48kHz：PCM1865 + PCM5102A 共享 MCLK/BCLK/LRCK
- PCM1865 需要 SCKI = 256/384/512fs；Pico PIO 生成
- ADS8688 独立扫描，1–8kHz
- PCM1865 I2C/SPI 地址需确认；一颗时无冲突

## 14. 已决定 / 不做

### 已决定

- JP-8000 风格 supersaw，8 voice，32/56 个振荡器
- 4× Audio Mod（PCM1865）+ 8× CV Mod（ADS8688）+ Sync
- Audio Matrix 4×5 amount；CV Matrix 8×25 depth
- CV Matrix destination-centric；量在目标调
- 6 个编码器：5 参数 + 1 导航；预设
- 一颗 PCM1865；第二颗暂不设计
- PCM5102A 立体声输出，10Vpp
- RP2350 / Pico 2 推荐
- 不做 LFO / Gate / Trig / Feedback / Symmetry / 第二 V/oct / 第二振荡器 / Clock
- Waveform、Octave 用面板按钮/开关，不走 CV

### 不采用

- ADS8588S / ADS8598H / LTC2348-18 / AD7606C-18：太贵
- AD8279 + DAC8568 / AD5764R / DAC8718：CV DAC 路线，成本/复杂度不合适
- 2× PCM1865：4 路 Audio Mod 已够
- 共享 Mod Bus + 只有目的地深度：无法独立控制每个输入
- 源侧 CV 路由列表：改为 destination-centric CV Matrix
- 4 个编码器：改为 5 参数 + 1 导航

## 19. 2026-10-20 修订：回到单独 VCO（当前有效）

> 本节是当前有效方案。前面章节中关于“通用可编程平台”、8 CV In/Out、8 Gate Out、6 编码器、2× PCM1865、DAC8568/DAC8564 的内容，与本节冲突的，一律以本节为准。

### 19.1 方向

- 放弃“通用可编程 DSP 平台”（VCO / VCF / MIDI-to-CV 复用）。
- 只做一台 **JP-8000 风格 supersaw 复音 VCO**。
- 不做 CV Out、Gate Out、MIDI Out/Thru、Sync Out。
- 不做 VCF / MIDI-to-CV / LFO 固件。
- 目标：缩小面板、降低复杂度，不再被 30+ 接口吃掉。

### 19.2 当前接口

| 类别 | 数量 | 芯片/方式 | 说明 |
|---|---:|---|---|
| **Audio In** | 4 | PCM1865 | 音频速率，AC 耦合 |
| **CV In** | 4 | ADS8688（8ch 只用 4） | DC 耦合；CV1 = V/oct 锁定 |
| **Audio Out** | 4 | PCM1681（8ch 只用 4） | 4 路音频输出 |
| **MIDI In** | 1 | 3.5mm TRS + 光耦 | 复音 MIDI |
| **Sync In** | 1 | 比较器 + GPIO/PIO | Hard/Soft |
| **USB-C** | 1 | Pico 2 | 烧录 / USB-MIDI |

- DAC/ADC 相关插孔：**4 + 4 + 4 = 12 个**
- 面板总接口：**12 + MIDI In + Sync In + USB = 15 个**
- 面板宽度：**18HP = 91.44mm**（90mm 的最近标准 HP）
- 如果 18HP 太挤，可放宽到 **20HP = 101.6mm**

### 19.3 芯片决定

| 功能 | 芯片 | 通道 | 说明 |
|---|---|---:|---|
| Audio ADC | **PCM1865** | 4 | 24bit/192k、110dB、PGA、I2C/SPI、TSSOP-30、3.3V |
| CV ADC | **ADS8688** | 8（只用 4） | 16bit、±10.24V/±5.12V、1MΩ、±20V OVP、SPI |
| Audio DAC | **PCM1681** | 8（只用 4） | 24bit/192k、105dB、单端 3.75Vpp、TSSOP-28、5V 模拟/3.3V 数字 |
| MIDI 光耦 | 6N138 / 6N137 | — | 31250 baud |
| 音频输出运放 | OPA1612 | 4 通道 | 2 颗双运放 |
| Audio In 缓冲 | OPA4197 / OPA2320 | 4 通道 | 1 颗四运放 |

#### 不采用的芯片

- **ADS8684 / DAC8564**：4 通道版本反而比 8 通道贵，放弃。
- **ADS8688 2 通道版本**：不存在；ADS868x 只有 1/4/8 通道。
- **PCM1862**：4ch/103dB，可做 Audio Mod 的低成本替代；**不能做慢速/DC CV**。
- **ADS8588S / ADS8598H / LTC2348-18 / AD7606C-18**：太贵，放弃。
- **AD8279 / DAC8568 / AD5764R / DAC8718**：没有 CV Out 需求，全部放弃。
- **2× PCM1865 / 8 Audio In**：4 路 Audio Mod 已够，放弃。
- **PCM 系列 4 通道音频 DAC**：现役没有；PCM1681 8ch 用 4ch 最实际。

### 19.4 Audio Mod 输入

PCM1865 不能直接吃 10Vpp：

- 模拟输入绝对最大：**−1.7V ～ 5.0V**
- 单端满量程：**2.1Vrms = 5.94Vpp**
- 10Vpp 必须外部衰减

输入级：

```
Jack → 1k + BAV99 → 100k 输入缓冲 → 0.5 衰减 → 10µF → PCM1865
```

- 10Vpp → 5Vpp，约 1.5dB headroom
- AC 耦合，PCM1865 输入自偏置 AVDD/2
- 输入折算 SNR：
  - PCM1865 110dB → 约 **104dB**
  - PCM1862 103dB → 约 **97dB**（低成本备选）
- 4 路用 1 颗四运放；不是精密 DC 增益级，offset 被隔直
- PGA 设 0dB 左右，用于微调
- 前面 1k + BAV99 保护

### 19.5 CV Mod 输入

- **ADS8688** 8 通道，只接 4 路：
  - CV1：V/oct（锁定）
  - CV2–4：可分配（Detune / Mix / Shape / Spread 等）
- 直接接插孔：`1k + BAV99`，不需要运放
- 1MΩ、±20V OVP、±10.24V/±5.12V
- 每通道量程：
  - V/oct：±5.12V（0.19 cent/LSB）
  - 0–5V 功能：0–5.12V
  - ±5V/0–10V：±5.12V 或 0–10.24V
- 扫描 1–8kHz，DSP 平滑
- 未用的 4 路输入接地/悬空，固件只扫描 4 路
- 不买 ADS8684/2ch；8ch 更便宜、更容易买

### 19.6 Audio Out

- **PCM1681** 8ch，只接 4 路输出
- 24bit/192k、105dB、单端满量程 3.75Vpp
- TSSOP-28，5V 模拟 / 3.3V 数字，I2S/TDM
- 输出级：4× OPA1612 通道（2 颗双运放）
  - 3.75Vpp → 约 **2.67 倍** → 10Vpp
  - 每路：`10µF + 1k + BAV99` 到插孔
- 未用的 4 路输出悬空/测试点，固件送 0

### 19.7 MIDI In

- 3.5mm TRS MIDI In，Type A 为主，Type A/B 跳线
- 31250 baud，8N1
- 6N138/6N137 光耦 + 220Ω，5V 电流环
- Pico UART RX，3.3V
- 8 voice 分配 + voice stealing
- 解析：Note On/Off、Velocity、Pitch Bend、Aftertouch、CC1 Mod Wheel
- Velocity / Aftertouch / Mod Wheel / Bend 可作为 CV Matrix 虚拟 source（可选）
- GP14 私有总线：单独 VCO 版本可以删掉；如果保留，作为备用/集成

### 19.8 Sync

- 比较器 + GPIO/PIO，不走 ADC
- 0–5V/0–10V 输入，阈值/迟滞
- Hard/Soft Sync 在 DSP 实现
- Sync 不是 Gate/Trig；不做 Gate/Trig 输入

### 19.9 Audio Matrix

- 4 Audio Mod × 5 目的地 = **20 个 amount**
- 目的地：FM / PM / PWM / RM / AM
- UI：选择 Audio Mod 1–4；3 个编码器 + Shift 编辑
- **只调 amount，不调 depth**
- FM Lin/Exp 用面板钮子开关，DSP 公式切换，5–10ms 交叉淡化

### 19.10 CV Matrix

- 4 CV Mod × 25 目标 = **100 个 depth**
- 目标：
  - FM1–4、PM1–4、PWM1–4、RM1–4、AM1–4（20 个）
  - Detune、Mix、Shape、Spread、Waveform/Morph（5 个）
- **destination-centric**（Serum 风格）：先选目标，再调 CV depth
- 一个 CV 可同时送多个目标；多个 CV 可送同一目标，求和
- **只调 depth，不调 amount**
- V/oct 不参与矩阵
- 合成：

```
eff_audio[src][dest] = clamp(
    base[src][dest]
    + Σ_cv cv_depth[cv][(src,dest)] × cv_value[cv],
    −1, +1)

param[target] = base_param
    + Σ_cv cv_depth[cv][target] × cv_value[cv]
```

### 19.11 面板与 UI

- 编码器：**3 个**（9mm 推荐：Bourns PEC09 / ALPS EC09E / 国产 EC09）
- 按钮：**3 个小按钮**：PAGE / TARGET / SHIFT
- 屏幕：1.3" ST7789 240×240（或 0.96" OLED）
- 3 编码器 + Shift = **6 个虚拟旋钮**

页面：

| 页面 | TARGET | 3 编码器（正常） | Shift |
|---|---|---|---|
| Audio Matrix | Audio Mod 1–4 | FM / PM / PWM | RM / AM / Spread |
| CV Matrix | 25 个目标 | CV1 / CV2 / CV3 | CV4 |
| CV Input | CV1–4 | CV1 / CV2 / CV3 | CV4（Gain/Range） |
| Global | — | V/oct 范围 / Sync / Octave | 预设 / Waveform / 其他 |

- PAGE：切页面
- TARGET：切源/目标
- SHIFT：第二层
- 编码器按下：清零/独奏
- 长按 PAGE：返回/保存
- 预设：8–16 组，存 Audio Matrix + CV Matrix + CV Input + Global
- 所有变化做 slew/平滑，避免 zipper noise

### 19.12 DSP / 复音

- 8 voice，来自 MIDI In
- 8×4 = 32 个 saw（RP2040 可行，固定点）
- 8×7 = 56 个 saw（RP2350 / Pico 2）
- 推荐 RP2350 / Pico 2
- core0：音频 DSP
- core1：UI、ADS8688、PCM1865、PCM1681、MIDI、预设
- PolyBLEP 抗混叠
- 立体声 spread
- 8 voice 求和、限幅、DC 阻断
- 48kHz 音频域，PCM1865 + PCM1681 共享时钟

### 19.13 面板尺寸

```
DAC/ADC 插孔：12
  4 Audio In
  4 CV In
  4 Audio Out

其他面板接口：3
  MIDI In
  Sync In
  USB-C

合计：15 个面板接口
```

- **18HP = 91.44mm**：3 编码器 + 3 按钮 + 屏幕 + 15 接口，能做但偏密
- **20HP = 101.6mm**：更舒服，推荐如果空间允许
- 不再有 CV Out / Gate Out / MIDI Out / Sync Out

### 19.14 放弃 / 不做的内容

- 通用可编程平台（VCO/VCF/MIDI-to-CV 复用）
- CV Out 8 路、Gate Out 8 路、MIDI Out/Thru、Sync Out
- 8 Audio In、8 CV In、2× PCM1865
- 6 编码器 / 5+1 编码器
- ADS8684 / DAC8564（4ch 更贵）
- ADS8688 2ch（不存在）
- PCM1862 做慢速 CV（AC 耦合，不行）
- DAC8568 / AD5764R / DAC8718 / AD8279（没有 CV Out 需求）
- 4ch PCM 音频 DAC（现役没有；PCM1681 8ch 用 4ch）

### 19.15 待定 / 风险

1. PCM1865 还是 PCM1862（110dB vs 103dB，成本差）
2. CV In 4 路是否够：V/oct + Detune/Mix/Shape/Spread 只能选 3 个
3. Audio Out 4 路还是 2 路（PCM1681 8ch 用 4 vs PCM5102A 2ch）
4. MIDI 虚拟 source（Velocity/AT/Mod/Bend）是否本期实现
5. Sync 比较器的 AC/DC 耦合、阈值、迟滞
6. 3 编码器 UI 的页面/目标选择是否够顺手
7. 18HP 是否放得下 15 接口 + 3 编码器 + 屏幕 + 3 按钮
8. 预设数量/存储
9. ADS8688 未用通道接地/悬空方式
10. PCM1681 未用输出处理
11. EDA 文件改动由作者确认；AI 只提建议
