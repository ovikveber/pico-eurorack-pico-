每轨去耦电容（各一套）
---------------------------------------------------------------------------
+12V: C1 220uF + C2 100uF + C3 22uF + C4 10uF + C5 1uF + C6 100nF
-12V: C7 220uF + C8 100uF + C9 22uF + C10 10uF + C11 1uF + C12 100nF
+5V : C13 220uF + C14 100uF + C15 22uF + C16 10uF + C17 1uF + C18 100nF

保护
---------------------------------------------------------------------------
+12V: 16PININ.9/10(+12VIN) -> D1(SS54) -> +12V 母线; D2(SMBJ15CA) 到 GND
-12V: 16PININ.1/2(-12VIN) -> D3(SS54, 方向相反) -> -12V 母线; D4(SMBJ15CA) 到 GND
+5V : 16PININ.11/12(+5VIN) -> Q1(AO3401A, D进/S出) -> +5V 母线;
      Q1 G -> R3 100k -> GND; D5(BZX84C10) 阴极->S、阳极->G; D6(SMBJ5.0CA) 到 GND

LED 指示（母线侧，通电亮，短路/掉电灭）
---------------------------------------------------------------------------
+12V: +12V -> R1 1k -> LED1 -> GND
-12V: GND -> R2 1k -> LED2 -> -12V
+5V : +5V -> R4 1k -> LED3 -> GND
注：12V 轨 1k 约 10mA、耗散约 0.1W；建议 0603 改 0805 或电阻改 2.2k。

接线（输出座并联到母线）
---------------------------------------------------------------------------
16P (CN2~CN10): 1/2=-12V  3~8=GND  9/10=+12V  11/12=+5V  13/14=CV  15/16=Gate
10P (CN17~CN25): 1/2=-12V  3~8=GND  9/10=+12V
