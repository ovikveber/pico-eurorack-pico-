电源分压板 项目日志
====================
版本：1.0（原理图 + PCB 已完成，DRC 通过）
日期：2026-10-30
EDA 项目：power板子（uuid 05cb080e...）

一、需求
--------
- Eurorack 电源分配板，装在 84HP 机箱内，板宽按实际可放下的尺寸做（约 56HP）。
- 输入来自 PSU：+12V / -12V / +5V / GND，用 1 个 16P 牛角座。
- 多路输出：16P + 10P 插座并联到各电源母线。
- 只在"入口"做保护（不做每路独立保护 / PTC）：
  * ±12V 反接保护 + TVS；
  * +5V P-MOS 反接保护 + 齐纳栅源钳位 + TVS。
- 每轨做一套去耦电容组：220uF / 100uF / 22uF / 10uF / 1uF / 100nF。
- 每轨一个 LED 指示：通电亮；掉电或后级短路把母线拉低时灭。

二、方案决定
------------
- 输入：单个 16P（CN 名 16PININ）。原计划的第二路 10P 输入已删除。
- 输出数量：原计划 10×16P + 10×10P = 20 路。因板宽放不下，删除 2 个插座，
  最终 9×16P（CN2~CN10）+ 9×10P（CN17~CN25）= 18 路（有意为之，非遗漏）。
- 插座全部并联到受保护母线，不做每路保险；接受"一路短路会拉低该轨、影响全板"
  的取舍，靠 PSU 限流兜底。
- 网络命名：输入侧 +12VIN/-12VIN/+5VIN，受保护母线 +12V/-12V/+5V；GND 统一。
- CV/Gate 走总线透传（13/14=CV，15/16=Gate），并联到输入。

三、保护与去耦（定稿）
----------------------
+12V: 16PININ.9/10 -> D1 SS54(阳极进/阴极出) -> +12V ; D2 SMBJ15CA 到 GND
-12V: 16PININ.1/2 -> D3 SS54(阴极进/阳极出, 方向与 +12V 相反) -> -12V ; D4 SMBJ15CA 到 GND
+5V : 16PININ.11/12 -> Q1 AO3401A (pin3=D 进, pin2=S 出) -> +5V ;
      Q1 pin1(G) -> R3 100k -> GND ; D5 BZX84C10(阴极->S, 阳极->G, pin2 NC) ;
      D6 SMBJ5.0CA 到 GND
去耦：
  +12V: C1 220uF, C2 100uF(固态), C3 22uF, C4 10uF, C5 1uF(CBB), C6 100nF(CBB)
  -12V: C7 220uF, C8 100uF(固态), C9 22uF, C10 10uF, C11 1uF(CBB), C12 100nF(CBB)
  +5V : C13 220uF, C14 100uF(固态), C15 22uF, C16 10uF, C17 1uF(CBB), C18 100nF(CBB)
  注：-12V 轨电解电容极性反装（+ 接 GND，- 接 -12V）。

四、LED 指示
------------
+12V: +12V -> R1 1k -> LED1 -> GND
-12V: GND -> R2 1k -> LED2 -> -12V
+5V : +5V -> R4 1k -> LED3 -> GND
说明：LED 是并联小负载，不产生大纹波、不拉低母线；只有它自己的 ~10mA 支路电流。
     12V 轨 1k 时约 0.1W，0603 偏紧，建议 0805 或改 2.2k。

五、PCB
-------
- 层数：2 层（Top / Bottom），双面 GND 铺铜。
- 板框：11200 x 1378 mil = 284.5 x 35.0 mm ≈ 56HP。
- 走线：电源母线 1.8~2.0mm（+12V 约 1.8mm，±12V 约 2.0mm，+5V 约 1.8mm）；
        CV/Gate 0.3mm；LED 支路 0.7mm。
- 摆位：输入座 + 保护 + 去耦集中在左侧，输出插座向右排列。
- 所有元件在 Top 层（单面贴装；连接器为 THT）。
- 无安装孔（待补）。

六、检查结论（2026-10-30）
--------------------------
- 原理图：18 个输出座脚位全部符合 Eurorack 标准，无错接/漏接；空脚仅 D5.2(NC)。
- 数据手册：SS54/SMBJ15CA/SMBJ5.0CA/AO3401A/BZX84C10 及电容耐压均满足。
- DRC：通过（0 错误）。
  * 曾报 CV/Gate 走线 0.3mm < 最小 0.5mm；已将设计规则最小线宽改为 0.2mm，通过。
    0.3mm 满足嘉立创 0.127mm 下限。
  * 曾报 +5V 的 Q1_2、D6_1 与母线不连通；已补线修复。
- 板宽：实测 56HP，非早期设想的 80HP（按实际放置）。
