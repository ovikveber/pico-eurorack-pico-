# 电源模块（Eurorack PSU）

Eurorack 电源模块：输入 **18V DC / 3A**，前级三颗 TPS5430，后级 LDO，
输出 **+12V / −12V / +5V，每路 1A**。输出接口 **16pin + 10pin**，
带三路电流检测和 10 段条显示。

> 设计细节、计算和待办都在 [`项目日志.md`](项目日志.md)。

## 当前状态（已打样，2026-10-28 实机调试）

- 输入：**18V DC / 3A（54W）**。
- 前级：三颗 **TPS5430**（内部补偿），输出 **+13.5V / +6.5V / −13.5V**，各 1A。
- 后级：**LM2940-12** → +12V/1A，**LM2940-5.0** → +5V/1A，**LM2990T-12** → −12V/1A。
- 三颗 LDO 1A 时各约 1.5W，需要小散热片或大铜皮。
- −13.5V 用反相 Buck-Boost，IC 地不是系统地。
- **实机结果**：±12V、+5V 已正常输出。
  - **LM2990T-12 买到假货/错标**：pin1 接地时输出只有约 −1.6V，行为像 LM337。
    换 **7912** 临时替代后 −12V 正常。7912 引脚与 LM2990 相同，但前级 −13.5V
    在满载时压差可能不够，且 TO-220 tab 需确认并绝缘散热片。
  - **D7 方向**：网表/丝印为 A=PH、K=−13.5V，实物需**反装**（A=−13.5V、K=PH）
    −13.5V 才正常；下版必须修正封装/符号。**D10 方向正确，不要跟着翻**。
- 其他已知：输入/输出没有 PTC/保险丝，过流靠 TPS5430 限流与 LDO 热关断兜底
  （2026-10-28 决定暂不加）。

## 下一步
