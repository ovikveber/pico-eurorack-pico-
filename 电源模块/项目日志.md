## 1. 为什么是 TPS5430 + 18V
### 1.1 TPS5410 做 −12V 只有约 0.63A
反相拓扑：
```
I_L(avg) = I_out / (1 − D)
D = |Vout| / (Vin + |Vout|)
```
15V → −13.5V 时 D≈0.474，1A 输出需要电感平均 1.9A；
TPS5410 峰值限流最小 1.2A → 最大约 0.63A。所以 TPS5410 出局。

### 1.2 TPS5430 够 1A，而且简单
- 3A 连续 / 4A 峰值，反相 1A 时电感平均约 1.8A，余量足够。
- **内部补偿**：不需要 RT 电阻、COMP 网络、EN 分压，外围比 TPS54360 少很多。
- 18V 输入时反相 −13.5V 的 IC 承受 `18+13.5=31.5V`，36V 耐压还剩 4.5V。

### 1.3 为什么输入 18V
- LM2940-12 / LM2940-5.0 / LM2990T-12 最坏 dropout 都是 **1V @1A**；
  +12V 需要 Buck 出 ≥13.0V，−12V 需要 ≤−13.0V，+5V 需要 ≥6.0V。
  各留 0.5V 余量，定前级 **+13.5 / +6.5 / −13.5V**。
- TPS5430 最大占空比最小 87%，18V 输入出 13.5V 还有约 1.8V 余量。
- 18V 时反相 −13.5V 的 IC 承受 31.5V，36V 耐压余量 4.5V；19V 只剩 3.5V。
- 18V/3A 适配器常见，输入满载约 2.1A。

### 1.4 后级 LDO
| 轨 | 器件 | 封装 | 电流 | 输出 | dropout | 前级输入 |
|---|---|---|---|---|---|---|
| +12V | **LM2940-12** | TO-220 / TO-263 | 1A | 12V 固定 | 0.5V typ / **1V max** | 13.5V |
| +5V | **LM2940-5.0** | TO-220 / TO-263 | 1A | 5V 固定 | 0.5V typ / **1V max** | 6.5V |
| −12V | **LM2990T-12** | TO-220 / TO-263 | 1A | −12V 固定 | 0.6V typ / **1V max** | −13.5V |

- **LM2990T-12 是固定 −12V，不需要 ADJ 电阻**；三端 IN / GND / OUT，
  比 LM2991 少两个电阻和 ON/OFF。
- 1A 时三颗各约 **1.5W**，TO-220 建议小散热片或大铜皮；TO-263 要铺铜。
- **不再用 78/79、TPS54360、TPS7A8500**：要么外围多，要么贵/难焊。

| 前级拓扑 | Buck | Buck | 反相 Buck-Boost |
| Buck 输出 | +13.5V / 1A | +6.5V / 1A | −13.5V / 1A |
| 后级 LDO | LM2940-12 | LM2940-5.0 | LM2990T-12 |
| 最终输出 | +12V / 1A | +5V / 1A | −12V / 1A |

| 实际 Buck 输出 | ≈13.43V | ≈6.49V | ≈−13.43V |
| 电感 | 22µH / Isat≥3A | 22µH / Isat≥3A | 22µH / Isat≥3A |
| 续流二极管 | SS54（5A/40V） | SS54 | SS54 |
| BOOT 电容 | 10nF / 50V | 10nF / 50V | 10nF / 50V |

| 输出电解 | 220µF/25V，ESR 0.04–0.1Ω | 220µF/16V，ESR 0.04–0.1Ω | 220µF/25V，ESR 0.04–0.1Ω |

| 开关频率 | 500kHz（固定） | 500kHz | 500kHz |

### 2.1 反馈电阻计算
```
Vout = 1.221 × (1 + R1/R2)
+13.5V: R1/R2 = 13.5/1.221 − 1 = 10.05 → 100k / 10k（≈13.43V）
+6.5V : R1/R2 = 6.5/1.221 − 1  = 4.32  → 43.2k / 10k（≈6.49V）
−13.5V: 反相拓扑同样用 100k / 10k（≈−13.43V）
```
- **只有 FB 分压需要 1%**；其余电阻 5% 即可（1% 也便宜）。
- −12V 的分压网络接法不同：R1 从**系统地**接到 VSENSE，R2 从 VSENSE 接到 **IC 地（−13.5V）**。
- 后级 LM2990T-12 是固定 −12V，**不需要任何反馈电阻**。

### 2.2 电感与电流
```
+13.5V: ΔI = 13.5×(18−13.5)/(18×22µH×500k) ≈ 0.31A，峰值 ≈1.15A
+6.5V : ΔI = 6.5×(18−6.5)/(18×22µH×500k)   ≈ 0.38A，峰值 ≈1.19A
−13.5V: ΔI = 18×0.429/(22µH×500k)           ≈ 0.70A
        电感平均 = 1/(1−0.429) ≈ 1.75A，峰值 ≈2.10A
```
- 三路统一 **22µH / Isat≥3A / Irms≥2A / 低 DCR**（6×6 或 8×8 屏蔽电感）。
- −13.5V 那路峰值最高，别用 1A/2A 的小电感。

### 2.3 二极管
- 三路都用 **SS54（5A/40V）**；−13.5V 的二极管反压 `18+13.5=31.5V`，40V 够。
- 如果手里有 SS56（60V），也能用，余量更大。

## 3. 输入级
```
J1(5.5×2.1, 3A) → F1(3A 慢断) → Q1(P-MOS 反接保护) → C1/C2/C3 → 三路 TPS5430 VIN
```
| 位号 | 器件 | 说明 |
|---|---|---|
| J1 | DC 座 5.5×2.1 或 2.5，3A | 已买 |
| F1 | 3A 慢断保险 / PTC | 满载约 2.1A |
| Q1 | AO3401A（P-MOS，−4A/−30V） | `D→输入+`、`S→后级`、`G→10k 到 GND` |
| DZ1 | BZX84C10（10V 稳压管） | 接在 Q1 的 G-S 之间 |
| C1 | 220µF/25V 电解 | 输入储能 |
| C2 | 10µF/25V X5R | 高频去耦 |
| C3 | 0.1µF/50V | 高频去耦 |

- **Q1/F1 只是输入保护，不是第四个变换器**；不想装 Q1 可以直连。
- **TVS 不装**：18V 输入时，TVS 钳位会经过反相级把 36V 的 TPS5430 推到 36V 以上。
- Q1 体二极管方向别接反；反接时体二极管反偏、Vgs≈0，MOS 关断。

## 4. 三路同时满载 1A
| 环节 | 数值 | 结论 |
|---|---|---|
| Buck 输出总功率 | 13.5×1 + 6.5×1 + 13.5×1 = **33.5W** | — |
| 输入功率（按 88%） | ≈**38W** | — |
| 18V 输入电流 | ≈**2.1A** | 3A 适配器/座/保险够 |
| +13.5V TPS5430 | 输出 1A，电感峰值 ≈1.15A | 3A/4A 器件，轻松 |
| +6.5V TPS5430 | 输出 1A，电感峰值 ≈1.19A | 轻松 |
| −13.5V TPS5430 | 输出 1A，电感平均 ≈1.75A，峰值 ≈2.1A | 3A 连续/4A 限流，够 |
| LM2940-12 | 1A，压差 1.43V → **≈1.43W** | 1A 额定；TO-220 小散热片/铺铜 |
| LM2940-5.0 | 1A，压差 1.49V → **≈1.49W** | 1A 额定；TO-220 小散热片/铺铜 |
| LM2990T-12 | 1A，压差 1.43V → **≈1.43W** | 1A 额定；TO-220 小散热片/铺铜 |

**结论：三路同时 1A 可行。瓶颈是三颗 LDO 的散热，不是 TPS5430，也不是输入电流。**
- 18V/3A 适配器要选**持续 3A** 的。

## 5. 接线
### 5.1 TPS5430 引脚
`1 BOOT / 2,3 NC / 4 VSENSE / 5 ENA / 6 GND / 7 VIN / 8 PH / DAP=GND`

### 5.2 +12V、+5V（普通 Buck）
```
VIN(18V) ──┬── VIN(7)
           ├── 10µF/25V + 0.1µF → GND
           └── ...

VIN ──[内部高侧 MOS]── PH(8) ──[22µH]── Vout
                              │
                         SS54 │（阴极接 PH，阳极接 GND）
                              │
                             GND

BOOT(1) ──[10nF]── PH(8)
Vout ──[R1]── VSENSE(4) ──[R2]── GND
ENA(5) 悬空（内部上拉，默认使能）
GND(6)/DAP ── 系统地
```
- 输出电容从 Vout 到 GND：220µF 电解 + 10µF 陶瓷 + 0.1µF。
- 二极管方向别反：**阴极接 PH，阳极接 GND**。

### 5.3 −12V（反相 Buck-Boost）
```
+18V ──┬── VIN(7)
       ├── C1 10µF/25V → 系统地（0V）
       └── C4 10µF/50V → IC 地（−13.5V，此电容承受 31.5V）

PH(8) ──[22µH]── 系统地（0V）
  │
  ├── SS54 阳极
  │
IC 地（−13.5V）── SS54 阴极

IC 地（−13.5V）= GND(6)/DAP = 输出 −13.5V
系统地（0V）  = 输入返回 = 输出 0V

BOOT(1) ──[10nF]── PH(8)
系统地(0V) ──[R1 100k]── VSENSE(4) ──[R2 10k]── IC 地(−13.5V)
输出电容：系统地(0V) ──[220µF + 10µF + 0.1µF]── IC 地(−13.5V)
ENA(5) 悬空
```
- **IC 的 GND/DAP 不是 0V，是 −13.5V**；散热铜皮也只接 −13.5V，绝不能接系统地。
- 输入电容要两只：C1 跨 VIN–系统地，C4 跨 VIN–IC 地（承受 31.5V）。
- 反馈分压的“上端”是系统地，“下端”是 IC 地。

### 5.4 后级 LDO
```
+13.43V ──[10µF/25V]── LM2940-12 ──[22µF/25V 电解 + 0.1µF]── +12V
GND ──────────────────── GND

+6.49V ──[10µF/16V]── LM2940-5.0 ──[22µF/16V 电解 + 0.1µF]── +5V
GND ──────────────────── GND

−13.43V ──[10µF/25V]── LM2990T-12 ──[10µF/25V 电解 + 0.1µF]── −12V
GND ──────────────────── GND
```
- LM2940/LM2990 的输入输出电容不能只留陶瓷：需要 10µF 以上、带一定 ESR 的电解/钽。
- LM2990T-12 是固定 −12V，三端 IN/GND/OUT，不需要 ADJ/ON-OFF。
- 三颗 LDO 在 1A 时各约 1.5W，TO-220 加小散热片或大铜皮；TO-263 要铺铜。

## 6. 布局 / 布线要点
1. **PowerPAD 必须焊**：TPS5430 的 DDA 封装底部散热焊盘要接铜皮并打多个过孔。
2. **输入陶瓷电容 10µF 紧贴 VIN/GND**，回路越小越好；大电解可以远一点。
3. **PH 节点铜皮要小**：PH → 电感 → 二极管这个高频回路面积最小化。
4. **反馈线远离 PH 和电感**，从输出电容正端取样；分压电阻靠近 VSENSE。
5. **BOOT 电容 10nF 紧贴 BOOT–PH**。
6. **−12V 反相级的地不是系统地**：
   - TPS5430 的 GND / PowerPAD 接 **−13.5V 输出**，不是 0V。
   - 输入电容：C1 从 VIN 到**系统地**；另加 C4（10µF/50V）从 VIN 到 **IC 地（−13.5V）**。
   - 输出电容：从**系统地**到 **IC 地（−13.5V）**。
   - 反馈：R1 从**系统地**到 VSENSE，R2 从 VSENSE 到 **IC 地**。
   - −12V 这一路的铜皮单独划区，**不要和系统地连在一起**。
7. 三路 500kHz 不同步，输入纹波会叠加；输入 220µF 电解 + 10µF 陶瓷不能省。
8. 输出电解的 ESR 选 **0.04–0.1Ω**（低 ESR 电解/聚合物），这是 TPS5430 内部补偿需要的；
   不要只留陶瓷电容，否则需要额外补偿网络。

## 9. 绘制进度存档（2026-10-18 睡前）
工程：`eurorack power` / Board1 / Schematic1 / P1。

### 9.1 输入
- U4：DC005，1 脚中心 → D4 阳极，3 脚外套 → GND，2 脚悬空。
- D4：SS54，阴极 → +18V。
- C16：220µF/50V，接在 +18V 和 GND（D4 之后）。

### 9.2 U1：+13.5V（TPS5430）
- U1 VIN +18V，GND/PowerPAD 接 GND，ENA/NC 悬空。
- C19 10nF：BOOT–PH。
- L1 22µH：PH → +13.5V。
- D5 SS54：阴极 PH，阳极 GND。
- 输出：C20 220µF/50V、C21 10µF/50V、C22 100nF，均在 +13.5V–GND。
- 输入：C17 10µF/50V、C18 100nF，在 +18V–GND。
- 反馈：R19 100k（+13.5V→VSENSE）、R20 10k（VSENSE→GND）。

### 9.3 U2：+6.5V（TPS5430）
- U2 VIN +18V，GND/PowerPAD 接 GND，ENA/NC 悬空。
- C25 10nF：BOOT–PH。
- L2 22µH：PH → +6.5V。
- D6 SS54：阴极 PH，阳极 GND。
- 输出：C26 220µF/50V、C27 10µF/50V、C28 100nF，均在 +6.5V–GND。
- 输入：C23 10µF/50V、C24 100nF，在 +18V–GND。
- 反馈：R2 43.2k（+6.5V→VSENSE）、R8 10k（VSENSE→GND）。

### 9.4 U3：−13.5V（反相）
- U3 VIN +18V；GND/PowerPAD 接 **−13.5V**；ENA/NC 悬空。
- C29 10nF：BOOT–PH。
- L3 22µH：PH → **GND**（不是 −13.5V）。
- D7 SS54：**阳极 PH，阴极 −13.5V**。
- C30 10µF/50V：+18V–GND。
- C31 10µF/50V：+18V–**−13.5V**（承受约 31.5V，必须 50V）。
- 输出：C32 220µF/50V、C33 10µF/50V、C34 100nF，均在 GND–−13.5V；
  电解 **+ 接 GND，− 接 −13.5V**。
- 反馈：R6 100k（GND→VSENSE）、R9 10k（VSENSE→−13.5V）。

### 9.5 检查结论
- 三路 TPS 拓扑、反馈、二极管方向、电感位置都正确。
- 输出电解 C20/C26/C32 是 KNSCHA `DGA050M227G123S1AA`（220µF/50V），
  **ESR 未标**；TPS5430 内部补偿要 0.04–0.1Ω，建议换低 ESR 或 2×100µF 低 ESR 并联。
- C21/C27/C33 是 10µF/50V、ESR 1.3Ω，作为并联去耦可以，但不是低 ESR 主力。
- C31 已确认 50V；C32/C33 极性已改对。
- 三颗 TPS 的输入 10µF 电容均已在 +18V 上。

## 12. 2026-10-25 实机调试：假 LM2990，7912 临时替代

### 12.1 现象
- 前级 -13.5V 正常；进 U7（LM2990T-12）后输出只有 **-1.6V**（空载、接模块都差不多，接模块约 -1.53V）。
- U7 pin1=0V、pin2=-13.5V、pin3=-1.6V；不发热；-12V 对 GND 约 4.1k（R23 在，无短路）。
- C41/C42 是 10µF/50V 铝电解，极性正确（+ 接 GND，− 接 -13.5/−12），不是电容问题。
- D10：A=-13.5V、K=-12V，方向正确（负压 LDO 保护），不是 D10 问题。
- R23 4.7k，只有约 2.5mA，不会拉垮输出。

### 12.2 结论
- 这颗“LM2990T-12”是**假货/错标**：pin1 接 GND 时输出约 -1.25~-1.6V，
  符合 **LM337（ADJ 接地，基准 -1.25V）** 的行为。
- LM337 与 LM2990 引脚只差 pin1（ADJ vs GND），插上去能“工作”，但稳不了 -12V。
- 换 **7912** 后输出稳定 -12V，进一步确认原 LM2990 有问题。

### 12.3 D7 方向（重要）
- 网表里 D7 是 A=PH、K=-13.5V；按反相 Buck-Boost 的正确方向应该是 **A=-13.5V、K=PH**。
- 实物把 D7 **反过来装**（A 接 -13.5V，K 接 PH）后 -13.5V 正常。
- 下次改板要把 D7 的 A/K 在原理图/封装里改对，否则丝印会误导。
- D10 与 D7 不同：D10 的 A=-13.5V、K=-12V 是**正确**的，不要跟着翻。

### 12.4 7912 临时替代注意
- 7912 引脚与 LM2990 相同：pin1=GND、pin2=IN、pin3=OUT。
- 压差：7912 建议输入 ≤ -14.5V，1A 时压差约 2V；现在前级 -13.5V，
  **空载/轻载能稳 -12V，满载可能掉出调整区**。
- 散热：1A、1.5V 压差约 1.5W；若把前级改 -15V，约 3W，必须加散热片。
- tab：7912 不同批次 tab 可能接 IN（pin2）或 GND（pin1）；
  用万用表测 tab 对 pin1/pin2 确认，散热片绝缘。
- 最小负载：7912 可能要几 mA，R23 只有 2.5mA，必要时并 1k。
- 最终方案：换**正品 LM2990T-12**（立创/得捷/贸泽）；
  若坚持 7912，把前级改成 -15V（改 R6/R9）并加散热片。
